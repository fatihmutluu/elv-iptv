# engine-aether (`@elv/engine-aether`)

Apple-only Expo module (tvOS, iOS, iPadOS): the AetherEngine 7.66.1 `PlayerEngine` and its `AetherSurface` view (player core spec 6.2).

## Commands
- `pnpm --filter @elv/engine-aether typecheck` and `pnpm --filter @elv/engine-aether test` run TypeScript and Vitest checks.
- `swift test --package-path modules/engine-aether/ios` runs the pure Swift 6 core suite (`ElvAetherCoreTests` on macOS).
- `sh modules/engine-aether/scripts/check-build.sh project|app|archive <path>` verifies the generated Xcode project, `.app` or `.xcarchive`.

## API & Threading (`src/index.ts`, `ios/Core/`, `ios/Engine/`)
- `createAetherEngine(): PlayerEngine | null` (`null` without `ElvEngineAether`) wraps a native `Engine` shared object (`EngineObject`) via `@elv/playback`'s `bridgeNativeEngine` (`audioTrackSelection: true`, `subtitleTrackSelection: true`); `release()` disposes it idempotently (`OnDestroy` and `sharedObjectDidRelease` also dispose live engines).
- `AetherSurface({ engine, style?, resizeMode?, testID? })` renders `AetherSurfaceView` bound to that native object (details in `VIEW.md`), or `null` when absent, foreign or released. `aetherEngineVersion()` returns `AetherEngine.version`.
- `ios/Package.swift` builds `ElvAetherCore` and `ElvAetherCoreTests` in Swift 6 language mode (`.swiftLanguageMode(.v6)`); `ios/ElvEngineAether.podspec` compiles `Core/**/*.swift` + `Engine/**/*.swift` under Swift 5.9 with `'SWIFT_STRICT_CONCURRENCY' => 'targeted'`.
- JS commands (`load`, `retry`, `play`, `pause`, `seek`, `selectAudioTrack`, `selectSubtitleTrack`, `stop`, `recreate`) coordinate through `CommandFence` in `EngineObject` and hop to `@MainActor` (`EngineMainDriver` -> `EngineCore` -> `AetherBackend`), preserving queued `recreate` across synchronous `recreate + load`, fencing `.tracks` by `mediaEpoch` (stamping the latest in-epoch token so `pause`/`play`/`seek` never drop deduplicated `tracks`), and fencing other events by `(mediaEpoch, token)` before `SharedObject.emit` (`onEngineEvent`, `atMs` from `ProcessInfo.processInfo.systemUptime * 1000`).
- `ios/Core/` imports `Foundation` only (`< 300` lines per file): `CommandFence`, `EngineCore` (`+Playback`, `+Tracks`), `EngineTypes`, `MediaPlan`, `TrackSelection`, `TrackLanguage`, `LiveTsReader`, `LiveTsSniffer`, `LiveRecoveryPolicy`, `SubtitleLayout`, `URLSessionTransport`, `ByteFifo`, `ByteTransport`, `ConnectionGate`, `ResponseSniffing`, `ErrorMapping`, `Redaction`, and `StreamHttp`.

## Requests, Live TS Reader & Errors (`LiveTsReader`, `LiveTsSniffer`, `URLSessionTransport`, `ErrorMapping`, `Redaction`)
- `.liveTs` opens through `LiveTsReader` (`IOReader`, forward-only `seek == -1`, `discImageProbeEnabled = false`) over one ephemeral `EngineHttpSession` per `EngineObject` (`httpMaximumConnectionsPerHost = 1`, no cache, 10 s request timeout, lock-serialized `suspend`/`resume`/`cancel`, RFC 7230 / control-character header sanitization, origin-scoped redirect stripping via `sanitizeRedirectRequest`), retaining itself in flight until async `didCompleteWithError` releases its gate slot.
- `ConnectionGate` (`open` for `.liveTs`, `waitForClosed` barrier for `.hls`, `.vod` and `.liveTs -> .playlist` handoffs) waits up to 1,000 ms for older generations' requests to close (cancelling its timeout task immediately on normal close) plus a 25 ms CFNetwork socket-teardown settle window before opening a newer media.
- `LiveTsSniffer` classifies both initial `open()` and single-drop mid-stream reconnects (`classifyProgressive`, judging body bytes before `Content-Type` labels): non-2xx -> `status(<s>)`; `#EXTM3U` on open -> closes the GET and reloads as HLS via `hlsHandoffOptions(from:)` (resetting `.liveTs` startup fields); printable UTF-8 without >= 3 TS sync bytes (or an empty 2xx with a notice `Content-Type`) -> `connection-limit` (`notice`) without polluting `ByteFifo`; >= 3 TS sync bytes -> `.custom(reader, formatHint: "mpegts")` delivered via `ByteFifo` (suspends > 8 MiB, resumes < 4 MiB).
- `ErrorMapping` maps `407` -> `http-401`, `410`/`451` -> `http-404`, `458`/`460`–`463`/`469` -> `connection-limit` (preserving `httpStatus`), and treats `NSURLErrorDomain`, `NSPOSIXErrorDomain`, `kCFErrorDomainCFNetwork`, and `NWErrorDomain` as `network`. `Redaction.redactUrl` enforces strict allowlist redaction (`scheme://host(:port)/***/***.<safeExt>`), stripping user-info, `;matrix`, `?query`, and `#fragment`.

## Start Latency & Load Options (`MediaPlan`, `AetherLoadOptions`, `LiveRecoveryPolicy`)
- `.liveTs` sets Candidate C (`liveStartupGraceSeconds = 0`, `liveStartupSingleSegmentMinimumSeconds = 1.0`, `probesize = nil`, `maxAnalyzeDurationMicros = nil`), selected from the `Apple TV 4K (3rd generation)` `3 x 30` zap matrix (`--burst 8`: `289.9 / 137.0 / 218.1 ms`; `--burst 0`: `759.3 / 652.2 / 722.6 ms`; `0` limit responses, `0 ms` overlap).
- `.hls` and `.vod` cap `maxConcurrentSourceRequests = 1`; all loads default `displayCriteriaOwner = .host`, `generatesBackgroundScrubPreviews = false`, and `skipsContainerAttachments = true` (keeping VideoToolbox hardware video even when `softwareAudio` is set, since `AetherEngine` bridges unsupported audio automatically).
- URL-backed live `.hls` enables `hostRetriesExhaustedLiveReplay = true`, driving `retryLiveSourceRecovery()` through `LiveRecoveryPolicy` (`1s / 2s / 4s`, max 3 attempts per 60 s, reset on clock progress) before escalating to `liveSourceReset`.

## Playback, Tracks & Build (`AetherBackend`, `ElvEngineAether.podspec`, `embed-frameworks.sh`, `with-aether-frameworks.ts`)
- `AetherBackend` (`+Loading`, `+Subscriptions`, `+Tracks`, `AetherAudioSessionObserver`) lazily allocates `AetherEngine` (`backgroundPlaybackEnabled = false`, `preventsDisplaySleepDuringVideoPlayback = true`) on first `start()`/`rebuild()`, routing all Combine sinks through `onMainActor` with settled post-`willSet` values. On failed `load()`, `AetherBackend` closes `currentReader` immediately and reads `currentEngine.errorInfo` before falling back to `sourceOpenFailed`.
- `EngineCore` gates clock position/anchor updates on `framed && !seeking`, clamps finite seeks to `0...duration`, treats resumed VOD ending at `duration > 0 && position > 0` as clean `.ended`, and converts unrequested live `.paused` into `.rebuffering` + `play()` while preserving user pauses and `AetherAudioSessionObserver` call/route-removal pauses (`.systemPaused`).
- `TrackSelectionState` reconciles overrides at most once per load (`audioReapplied`/`subtitleReapplied` latches) using ISO 639-1/639-2/BCP-47 language equivalence and `label` tie-breaking, while `desiredAudioStreamId`/`desiredSubtitleStreamId` converge rapid track flip-flops and clear stale cues across switches.
- Never link MPVKit, VLCKit or a second FFmpeg copy; AetherEngine is pinned at exact `7.66.1` with optional traits off. `with-aether-frameworks.ts` + `embed-frameworks.sh` copy, `lipo`-thin, sign and archive dSYMs for the nine dynamic LGPL `AetherLib*.framework` binaries.
