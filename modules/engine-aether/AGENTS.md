# engine-aether (`@elv/engine-aether`)

Apple-only Expo module (tvOS, iOS, iPadOS): the AetherEngine 7.66.1 `PlayerEngine` and its `AetherSurface` view (player core spec 6.2).

## Commands
- `pnpm --filter @elv/engine-aether typecheck` and `pnpm --filter @elv/engine-aether test` run TypeScript and Vitest checks.
- `swift test --package-path modules/engine-aether/ios` runs the pure Swift 6 core suite (`ElvAetherCoreTests` on macOS).
- `sh modules/engine-aether/scripts/check-build.sh project|app|archive <path>` verifies the generated Xcode project, `.app` or `.xcarchive`.

## API & Threading (`src/index.ts`, `ios/Core/`, `ios/Engine/`)
- `createAetherEngine(options?): PlayerEngine | null` (`null` without `ElvEngineAether`) wraps a native `Engine` shared object (`EngineObject`, optional `{ handleAudioFocus?: boolean }` for Multi-View secondary tiles, `#34`) via `@elv/playback`'s `bridgeNativeEngine` (`audioTrackSelection`, `subtitleTrackSelection`, `audioDelay`, `subtitleDelay`, `videoQualitySelection`, `externalSubtitles`, `subtitleStyling`, `dualSubtitles`); `configureAetherMultiView(engine, handleAudioFocus)` promotes/demotes live audio-focus & Now Playing ownership; `release()` disposes idempotently (`OnDestroy` and `sharedObjectDidRelease` also dispose live engines).
- `AetherSurface({ engine, style?, resizeMode?, subtitleBottomInsetPx?, subtitleFontFamily?, subtitleStyle?, osdVisible?, testID? })` renders `AetherSurfaceView` bound to that native object (details in `VIEW.md`), or `null` when absent, foreign or released. `aetherEngineVersion()` returns `AetherEngine.version`; `getAppleDeviceModel()` / `ElvEngineAether.deviceModel()` exposes the machine identifier (with `SIMULATOR_MODEL_IDENTIFIER` fallback) for `resolveAppleHardwareTier`.
- Persistent KV bridge (`#79`, ADR 0014): `readApplePersistentValue`, `writeApplePersistentValue`, `writeAppleLocalPersistentValue`, and `getApplePersistentBudgetBytes` delegate to `ApplePersistentKVStore` (`PersistentStoreBudget.swift`), preferring entitled `NSUbiquitousKeyValueStore` (`900 KB` ceiling, gated by `embedded.mobileprovision` when present, `ubiquityIdentityToken != nil`, and `synchronize() == true`) while always mirroring byte-safe snapshots (`<= 384 KB`) to `NSUserDefaults.standard`.
- Output audio, safe-area, source import & iPadOS keyboard (`#415`, `#51`, `#182`): `setAppleEngineMuted` / `setAppleEngineVolume` persist and apply `AVPlayer.isMuted` / `AVPlayer.volume` across player instances; `getAppleSafeAreaInsets` / `subscribeAppleSafeAreaInsets` report live iOS safe-area insets (`onSafeAreaInsetsChanged`) and `subscribeAppleHardwareKeys` forwards iOS/iPadOS `UIKeyCommand` playback actions (`onHardwareKey`) through `AppleModuleEventHub`; `readAppleClipboardText` / `pickApplePlaylistFile` (`AppleSourceImport.swift`) expose iOS `UIPasteboard` and security-scoped `UIDocumentPickerViewController` (64 MiB cap) while safely returning `nil` on tvOS; `makeStreamSessionConfiguration(allowLegacyTls:)` enables opt-in TLS 1.0+ per source without downgrading the default modern TLS session.
- Now Playing, Remote Commands & Background Audio (`#413`, `#117`, `#34`): `setAetherMediaMetadata`, `setAetherBackgroundAudioEnabled`, `setAetherDetachedSurfaceAllowed`, `configureAetherMultiView`, and `subscribeAetherRemoteMediaAction` (`'next' | 'previous' | 'stop'` on `onRemoteMediaAction`) drive `AetherNowPlayingBridge` (`MPNowPlayingInfoCenter` + `MPRemoteCommandCenter`, gated by `NowPlayingOwnershipTracker` so muted secondary Multi-View tiles never overwrite/clear the primary tile's Now Playing state or remote commands), `NowPlayingPolicy` (credential-free artwork URL sanitization, live vs VOD capability gating, 5 s clock throttle with 1.5 s seek-jump pass-through, bounded <= 4 MiB async artwork fetch), and `EngineMainDriver`'s unified detached-surface policy (`allowDetachedSurface = backgroundAudioEnabled || explicitDetachedSurfaceAllowed || pipDetachedSurfaceAllowed`) while keeping `AetherEngine`'s built-in Now Playing flags off and `backgroundAudioEnabled` defaulting to `false`.
- Picture-in-Picture, Thermal Watchdog & Physical Memory (`#34`, `#232`): `enterAetherPictureInPicture`, `canStartAetherPictureInPicture`, `setAetherAutoEnterPictureInPicture`, and `subscribeAetherPictureInPicture` (`onPictureInPictureChanged`) drive `AetherPipController` (`AVPictureInPictureController` over the bound `AVPlayerLayer` located within bounded depth 6 inside `AetherSurfaceView.playerView`, guarding iOS-only `canStartPictureInPictureAutomaticallyFromInline` under `#if os(iOS)`, arming `EngineCore.setAllowDetachedSurface(true)` across PiP lifecycle, and returning `false` cleanly on raw-TS non-`AVPlayer` routes); `getAppleThermalState`, `subscribeAppleThermalState` (`ProcessInfo.thermalStateDidChangeNotification` -> `onThermalStateChanged`), and `getApplePhysicalMemoryBytes` (`ProcessInfo.processInfo.physicalMemory`) pair with pure Foundation `ThermalStateMapper` (`AppleThermalLevel`, `mapProcessInfoThermalState`, `resolveAppleMultiViewMaxTiles`).
- `ios/Package.swift` builds `ElvAetherCore` and `ElvAetherCoreTests` in Swift 6 language mode (`.swiftLanguageMode(.v6)`); `ios/ElvEngineAether.podspec` compiles `Core/**/*.swift` + `Engine/**/*.swift` under Swift 5.9 with `'SWIFT_STRICT_CONCURRENCY' => 'targeted'`.
- JS commands (`load`, `retry`, `play`, `pause`, `seek`, `setSpeed`, `setAudioDelay`, `setSubtitleDelay`, `selectAudioTrack`, `selectSubtitleTrack`, `selectVideoQuality`, `stop`, `recreate`) coordinate through `CommandFence` in `EngineObject` and hop to `@MainActor` (`EngineMainDriver` -> `EngineCore` -> `AetherBackend`), preserving queued `recreate` across synchronous `recreate + load`, fencing `.tracks`, `.mediaInfo`, and `.externalPlayback` by `mediaEpoch` (stamping the latest in-epoch token so `pause`/`play`/`seek` never drop deduplicated snapshots), and fencing other events by `(mediaEpoch, token)` before `SharedObject.emit` (`onEngineEvent`, `atMs` from `ProcessInfo.processInfo.systemUptime * 1000`).
- `ios/Core/` imports `Foundation` only (`< 400` lines per file): `CommandFence`, `DisplaySyncPolicy`, `EngineCore` (`+Playback`, `+Tracks`), `EngineTypes`, `LiveTimeShiftPolicy`, `MediaPlan`, `NetworkTransportOptions` (`DnsFamilyPreference` + strict IPv4/IPv6 `validateHostOverride`, `#172`), `TrackSelection`, `TrackLanguage`, `SyncDelayAndQualityPolicy`, `LiveTsReader`, `LiveTsSniffer`, `LiveRecoveryPolicy`, `SubtitleLayout`, `SubtitleBidi`, `ExternalSubtitleParser`, `SurfaceLayout`, `HardwareKeyboardShortcut`, `NowPlayingPolicy`, `PersistentStoreBudget`, `ThermalStateMapper`, `AirPlayCapability`, `AudioSessionPolicy`, `AudioSessionRefCounter` (`AetherAudioSessionRefCounter`, `NowPlayingOwnershipTracker`), `AVBufferEvaluation`, `CaptionAppearanceStyle`, `OsdClockThrottle`, `URLSessionTransport`, `ByteFifo`, `ByteTransport`, `ConnectionGate`, `ResponseSniffing`, `ErrorMapping`, `Redaction`, and `StreamHttp`.
- Subtitles suite (`#285`, `#308`, `#32`, `#402`): `SubtitleBidi` isolates RTL-first lines (`\u{2067}...\u{2069}` + `.rightToLeft` paragraph direction) and merges overlapping cues; `StreamHttp.makeSubtitleSession` streams external HTTP(S) sidecars incrementally (`session.bytes(for:)`, `<= 4 MiB` ceiling, isolated ephemeral session with cross-origin auth/cookie strip) and `ExternalSubtitleParser.readValidatedLocalSubtitle` validates `file://` URIs (no `..`, extension allowlist re-checked after symlink resolution, `<= 4 MiB`), parsed off `@MainActor` with linear O(N) scanners and bounded timestamps (`<= 86_400_000_000` ms); `applyingUserSubtitleStyle` + `updateSubtitleStyle` apply live styling without restart; `AetherBackend+ExternalSubtitles` + `AetherSubtitleOverlayView` render simultaneous primary (bottom) and secondary (`.topCenter`) subtitles (embedded+external, external+embedded, Off+embedded; embedded+embedded rejected since AetherEngine decodes one embedded stream at a time).

## Requests, Live TS Reader & Errors (`LiveTsReader`, `LiveTsSniffer`, `URLSessionTransport`, `ErrorMapping`, `Redaction`)
- `.liveTs` opens through `LiveTsReader` (`IOReader`, forward-only `seek == -1`, `discImageProbeEnabled = false`) over one ephemeral `EngineHttpSession` per `EngineObject` (`httpMaximumConnectionsPerHost = 1`, no cache, 10 s request timeout, lock-serialized `suspend`/`resume`/`cancel`, RFC 7230 / control-character header sanitization, origin-scoped redirect stripping via `sanitizeRedirectRequest`), retaining itself in flight until async `didCompleteWithError` releases its gate slot.
- `ConnectionGate` (`open` for `.liveTs`, `waitForClosed` barrier for `.hls`, `.vod` and `.liveTs -> .playlist` handoffs) waits up to 1,000 ms for older generations' requests to close (cancelling its timeout task immediately on normal close) plus a 25 ms CFNetwork socket-teardown settle window before opening a newer media.
- `LiveTsSniffer` classifies initial `open()` and mid-stream reconnects (`LiveTsReader` uses a time-windowed reconnect budget of 3 per 60 s, resetting after 30 s of stable streaming): non-2xx -> `status(<s>)`; `#EXTM3U` on open -> reloads as HLS via `hlsHandoffOptions(from:)`; printable UTF-8 without >= 3 TS sync bytes (or empty 2xx with a notice `Content-Type`) -> `connection-limit` (`notice`) without polluting `ByteFifo`; >= 3 TS sync bytes -> `.custom(reader, formatHint: "mpegts")` via `ByteFifo` (suspends > 8 MiB, resumes < 4 MiB).
- `ErrorMapping` maps `407` -> `http-401`, `410`/`451` -> `http-404`, `458`/`460`–`463`/`469` -> `connection-limit` (preserving `httpStatus`), and treats `NSURLErrorDomain`, `NSPOSIXErrorDomain`, `kCFErrorDomainCFNetwork`, and `NWErrorDomain` as `network`. `Redaction.redactUrl` enforces strict allowlist redaction (`scheme://host(:port)/***/***.<safeExt>`), stripping user-info, `;matrix`, `?query`, and `#fragment`.

## Start Latency & Load Options (`MediaPlan`, `AetherLoadOptions`, `LiveRecoveryPolicy`)
- `.liveTs` sets Candidate C (`liveStartupGraceSeconds = 0`, `liveStartupSingleSegmentMinimumSeconds = 1.0`, `probesize = nil`, `maxAnalyzeDurationMicros = nil`), selected from the `Apple TV 4K (3rd generation)` `3 x 30` zap matrix (`--burst 8`: `289.9 / 137.0 / 218.1 ms`; `--burst 0`: `759.3 / 652.2 / 722.6 ms`; `0` limit responses, `0 ms` overlap).
- `.hls` and `.vod` cap `maxConcurrentSourceRequests = 1`; all loads default `displayCriteriaOwner = .engine` (`DisplaySyncPolicy` maps `.off` + `!autoDynamicRange` -> `.host` and resets tvOS `AVDisplayManager.preferredDisplayCriteria`, while enabled tvOS playback snaps cinema/broadcast FPS ±0.15, drives `AVDisplayCriteria` on stabilized `mediaInfo` + live `setDisplaySync`, guards HDMI resync flicker via `AetherSurfaceView`'s 650 ms shutter settle window, preserves `resetDisplayCriteria: false` across live zaps/rebuilds, and resets on `userStop`/`dispose`, `#188`, `#116`), `generatesBackgroundScrubPreviews = false`, and `skipsContainerAttachments = true` (keeping VideoToolbox hardware video even when `softwareAudio` is set, since `AetherEngine` bridges unsupported audio automatically).
- URL-backed live `.hls` enables `hostRetriesExhaustedLiveReplay = true`, driving `retryLiveSourceRecovery()` through `LiveRecoveryPolicy` (`1s / 2s / 4s`, max 3 attempts per 60 s, reset on clock progress) before escalating to `liveSourceReset`.

## Playback, Tracks & Build (`AetherBackend`, `ElvEngineAether.podspec`, `embed-frameworks.sh`, `with-aether-frameworks.ts`)
- `AetherBackend` (`+Loading`, `+Subscriptions`, `+Tracks`, `+AirPlay`, `AetherAudioSessionController`, `AetherAudioSessionObserver`, `AetherAirPlayMonitor`) pre-warms `AetherEngine` (`backgroundPlaybackEnabled = false`, `preventsDisplaySleepDuringVideoPlayback = true`, `allowsExternalPlayback = true`) on `@MainActor`, configures `AVAudioSession` (`.playback`/`.moviePlayback`/multichannel toggled via `AirPlayCapabilityTracker` + lazy `_airplay._tcp` `NWBrowser` active ONLY during AirPlay routes or `isExternalPlaybackActive`, `#234`) on `start`/`play` and ref-counts active engines via `AetherAudioSessionRefCounter` so `.notifyOthersOnDeactivation` deactivation runs strictly when active owners drop `1 -> 0` across `stopMedia`/`rebuild`/`dispose`, and drives `AudioSessionPolicy` (immediate pause + latched `.systemPaused` on headphone/BT disconnect; `.shouldResume` interruption handling).
- `AetherBackend` observes `AVPlayer`/`AVPlayerItem` KVO via `evaluateAVPlayerBuffering` (`isPlaybackBufferEmpty` wins over `isPlaybackBufferFull`/`isPlaybackLikelyToKeepUp`; skipped while `isExternalPlaybackActive` is `true`), tears down item/subtitle observers via `clearPlayerItemObservers()` before item replacement/stop/rebuild/dispose and fences `AVPlayer`/`AVPlayerItem` callbacks and async tasks (`loadTask`, `mediaInfoTask`, `audioSwitchTask`, `seekTask`, `liveRecoveryTask`) by active engine & serial (`#117`), forwards `isExternalPlaybackActive` -> `BackendObservation.externalPlayback` (suspending local stall starts and display-sleep locks in `EngineCore` during AirPlay handoff), captures `$state == .error` metadata synchronously under `engineLoadSerial > 0 ? engineLoadSerial : activeLoadSerial`, loops `while let pendingSeek = self.seekTask` before `selectAudioTrack`, gates `$sourceTime` subscription on active non-empty subtitles, and throttles hidden-OSD `clock.$currentTime` ticks to `5.0 s` via `OsdClockThrottle`.
- `EngineCore` gates clock updates on `framed && !seeking && !reloading`, clamps VOD `setSpeed` to `[0.25, 4.0]` (resetting to `1.0` across load/retry/stop/recreate/release), decouples background, `allowDetachedSurface`, and AirPlay external-playback surface detach (`isSurfaceDetached`, restoring `screenOn` on foreground reattach, `#117`) from fatal foreground `surface-lost`, freezes mid-playback `.loading` reloads to `.buffering`, clamps finite seeks to `0...duration`, and converts unrequested live `.paused` into `.rebuffering` + `play()` while preserving user and `.systemPaused` pauses.
- `TrackSelectionState` reconciles overrides at most once per load (`audioReapplied`/`subtitleReapplied` latches) using ISO 639-1/639-2/BCP-47 language equivalence and `label` tie-breaking, while `desiredAudioStreamId`/`desiredSubtitleStreamId` converge rapid track flip-flops and clear stale cues across switches; `SyncDelayAndQualityPolicy` clamps audio/subtitle delays (`[-30_000, 30_000]` ms -> `setAudioDelay` / `setSoftwareSubtitleDelay` + overlay cue shift) and maps adaptive HLS ceiling presets (`2160p`/`1080p`/`720p`/`480p`/Auto) onto `AVPlayerItem.preferredMaximumResolution` & `preferredPeakBitRate` (`#59`).
- Never link MPVKit, VLCKit or a second FFmpeg copy; AetherEngine is pinned at exact `7.66.1` with optional traits off. `with-aether-frameworks.ts` + `embed-frameworks.sh` copy, `lipo`-thin, sign and archive dSYMs for the nine dynamic LGPL `AetherLib*.framework` binaries.
