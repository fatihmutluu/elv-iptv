# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Fixes land there first.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub private vulnerability reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**
(https://github.com/fatihmutluu/elv-iptv/security/advisories/new).

Include what you found, how to reproduce it and which platform and version are affected. Never include real playlist URLs or account credentials in a report.

You will get an acknowledgement as soon as the owner can review it, and updates until the issue is resolved.
