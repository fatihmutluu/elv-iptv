# Vega OS app (planned)

Planned, not started. Fire TV devices running Vega OS cannot run Android APKs, so they need a separate Vega app that shares the pure packages with the Expo app. The Expo SDK does not target Vega.
The app comes after Android TV and Fire OS are stable and is tested on a Vega Virtual Device, which needs a Mac or an Ubuntu VM.
No code is written until the work is scheduled; see [ADR 0010](../../docs/adr/0010-future-tvs-vega-tizen-webos.md).
