# tv-mobile (`tv-mobile`)

The single Expo app for Android phone/tablet, Android TV, Fire OS, iPhone, iPad and Apple TV.
It is a composition root: it wires modules, storage drivers, routes and stores.

## Commands
- `pnpm run:app <target> run|build` launches or prebuilds a target (see `tools/`).
- `pnpm --filter tv-mobile test` runs the config Vitest tests; `test:jest` runs component tests.
- `pnpm --filter tv-mobile exec expo-doctor` and `exec expo install --check` are release gates.

## Rules
- `android/` and `ios/` are generated by `expo prebuild`; never edit or commit them.
- `app.config.ts` only calls `config/build-app-config.ts`; put logic and tests there.
- Build variants come from env: `APP_VARIANT` (development|production), `EXPO_TV=1`,
  `STORE` (play|amazon|appstore|direct). No Gradle product flavors.
- `DEV_*` values reach `extra.dev` in development only; production builds must never contain them.
- One `react-native` copy: the root override aliases it to `react-native-tvos`.
- No Google Play Services or Firebase dependencies.
- The iOS and tvOS projects share `ios/`; generate one at a time (`expo prebuild --clean`).
- Placeholder images in `assets/` are generated once; replace them with final art, not code.
