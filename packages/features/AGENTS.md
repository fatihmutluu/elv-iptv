# features (`@elv/features`)

Screens and view models, one folder per feature, with ports for platform services and root-level `AppShell`.

## Commands
- `pnpm --filter @elv/features typecheck` type-checks this package.
- `pnpm --filter @elv/features test` runs pure Vitest unit tests (`>= 90%` line coverage).
- `pnpm --filter @elv/features test:jest` runs Jest + RNTL component and simulator tests.
- `pnpm -w check` runs every repository check.

## Rules
- **UI/UX Contract & Feature Placement (mandatory):** Read `docs/design/UI_UX_PHILOSOPHY.md` before implementing any screen, overlay, player control, or new user-facing feature — follow Cinema Quietude v2 placement (4+2 top-level cap, `Favorites | Channels | TV Guide` Live sub-modes, Movies/Series top `16:9` `Continue watching` rail, editorial underline category navigation via `EditorialCategoryBar`, 2-level player Settings popover / Portrait bottom sheet, Detail order `Hero -> Cast -> Season Dropdown & Episodes -> More Like This`, and the 10-point Pre-Merge UI Checklist).
- **Non-Overlay Top Spacing Rule:** Only overlay Hero screens (`Home`, `Detail`) apply `heroTopClearance`; non-overlay screens (`Live`, `Movies`, `Series`, `Search`, `Settings`) render below the in-flow top bar with tight `10–16px` top padding and MUST NOT apply `heroTopClearance`.
- Allowed workspace dependencies: `@elv/data`, `@elv/domain`, `@elv/focus-core`, `@elv/i18n`, `@elv/playback`, `@elv/ui-kit`.
- Never imports `modules/*`, `apps/*`, `expo-*`, navigation libraries or another feature's folder (`no-feature-to-feature`).
- Platform services (`PlaybackGuard`, `VideoHost`, `AppLifecyclePort`, `PlayTarget`) live under `src/ports/`.
- Source-first: `exports` points at `src/index.ts`; every focusable control carries a deterministic `testID` and `accessibilityLabel`.
- `src/AppShell.tsx` (with `app-shell-sections.tsx`, `app-shell-tv-channels.ts`, `app-shell-deep-link.ts`) composes canonical 4+2 nav (`Home`, `Live`, `Movies`, `Series` + `Search`, `Settings` utilities), `KeymapProvider`, overlay `detailStack` (`DetailScreen`), `ChannelManagementOverlay`, full-screen `PlayerScreen`, Android TV Home Screen preview channels sync (`#273`), and `elviptv://play` deep-link playback (`#273`) via `AdaptiveNavShell` (`#13`, `#14`, `#33`, `#60`, `#98`, `#325`).
- `src/search/` owns instant Turkish-tolerant `SearchScreen`, `SearchChrome`, `SearchResultsSection`, `search-model`, `useCatalogSearch`, and `useTvSearchNavigation` (6 editorial scope underline tabs including `On Now & Guide` and `Episodes`, grouped result sections, idle suggestions, zero pill-bubble category chips, `#14`, `#397`).
- `src/home/` owns flagship Cinema Quietude `HomeScreen`, `HomeHero` (`52–58%` viewport height so the first rail peeks above the fold), `HomeRail`, `HomeSkeleton`, `home-model`, bounded `useHomeData` (Continue Watching, On Air Now, My List, Featured Movies/Series), and `useTvHomeNavigation` (`#14`).
