# ui-kit (`@elv/ui-kit`)

React components for react-native and react-native-web, design tokens and TV focus primitives.

## Commands
- `pnpm --filter @elv/ui-kit typecheck` type-checks this package.
- `pnpm --filter @elv/ui-kit test:jest` runs its Jest component tests.
- `pnpm -w check` runs every repository check.

## Rules
- **UI/UX Contract (mandatory):** Read `docs/design/UI_UX_PHILOSOPHY.md` before changing tokens, themes, surfaces, focus states, buttons, cards, or layout primitives. Colors, scrims, and focus states must read dynamically from the theme provider (including WCAG AAA High Contrast).
- **Anti-Pill Category Rule:** Never use `999px` pill-capsule `FilterChip` buttons for category navigation across Live, Movies, Series, or Search; use borderless `EditorialCategoryBar` underline tabs (`1px` hairline + `2px` accent active bar + `Categories ▾` popover when `> 6` categories).
- May import `react` and `react-native`; never `expo-*`, navigation libraries, or `electron`. Allowed workspace deps: `@elv/domain`, `@elv/focus-core`, `@elv/i18n`. Never imports `features`, `modules/*`, or `apps/*`. Source-first (`src/index.ts`).
- Layout forks happen via `useViewport()` (which also keeps `useFormFactor()` in sync via `ViewportProvider`/`FormFactorProvider`), never by file-name suffix. `I18nProvider`/`useI18n` subscribe to `@elv/i18n` via `useSyncExternalStore`.
- TV code never uses `Modal` (Biome enforces it); overlays (`AdaptiveSheet`) are focus-scoped views in the main window.

## Design System Core (`src/theme/`, `src/viewport/`, `src/adapters/`, `src/icons/`, `src/primitives/`)
- **Theme (`src/theme/`):** `ThemeProvider`, `useTheme`, `useThemeController`, `buildTheme`, `THEME_PRESETS` (`obsidianCrimson`, `abyssalSapphire`, `theaterAmber`, `velvetViolet`, `pitchEmerald`, WCAG AAA `highContrast` #325), `contrastRatio`, `hexToRgba`, `clampFontScale` (`[0.9, 1.2]`), `uiFontFamily` (`'system' | 'atkinson' | 'opendyslexic'` per-weight native & web typography, #163), `FONT_FAMILY_SANS`, `TABULAR_NUMS_STYLE`, and web-only CSS helpers (`webTransition`, `webBackdropBlur`, `webShadow`, `webCursorPointer`). Scrims/glass/chips/hover borders derive dynamically; `ThemeProvider` injects an idempotent `<style id="elv-ui-kit-web-base">` on web; `reduceMotion` collapses durations to `0`, CSS transitions to `'none'`, and focus scale to `1.0`.
- **Viewport (`src/viewport/`):** `ViewportProvider`, `useViewport`, `resolveViewport`, `scaleTv` return `{ formFactor, orientation, inputModality, width, height, safeArea, overscan, columns, tvScale }` normalizing Android TV (`960x540dp`) vs tvOS (`1920x1080pt`) (#281), configurable TV `overscanX`/`overscanY` ratios (`[0, 0.1]`, default `0.05`, #133), and responsive viewport-proportional `columns` (`posterRail`, `wideRail`, `categoryGrid`) across phone, tablet, TV, and `1280px–1920px+` desktop so cards never bloat on wide monitors.
- **Adapters & Icons (`src/adapters/`, `src/icons/`):** `UiAdaptersProvider`/`useUiAdapters` inject optional native `renderGradient`/`renderBlur`/`renderImage`/`renderSvg`. `Icon` renders typed `IconName` specs from `ICON_PATHS` (including `volumeMute`, `fullscreen`, `fullscreenExit`, `star`, `starFilled`, `chevronLeft`, `chevronDown`).
- **Primitives (`src/primitives/`, `src/components/`):** `Surface`, `Scrim`, `GlassBar`, `SkeletonBox` (zero-CLS tonal placeholder), `ArtworkImage` (`zoomed` hover scale + `DeadHostRegistry`, #126, #202, #311), `AdaptiveSheet`, `ErrorBoundary` (#159), `CtaButton`, `IconButton`, `MicroPill`, `FilterChip`, `HorizontalRailScroll` + `attachHorizontalDragScroll` (touch swipe, pointer click-and-drag with drag-threshold click suppression, wheel/Shift+Wheel pan, hover edge chevrons), `EditorialCategoryBar`, `AlphabetJumpRail` (`#`, `A–Z` jump strip with pointer/touch vertical scrubbing preview and custom TV D-pad focus highlight, #407), `PosterCard` (`2:3`, memoized, `maxDecodePx=320`), `WideCard` (`16:9`, memoized, `maxDecodePx=480`, bottom scrim & optional circular `showPlayBadge`). Zero boxed media cards, zero duplicate titles, zero neon desktop hover rings.

## TV focus, remote dispatcher & lists (`src/tv/`, `src/list/`)
- **Dispatcher (`remote-dispatcher.ts`, `key-source.ts`, `remote-context.ts`):** `TvRemoteProvider`/`createTvRemoteDispatcher(lifecycle?)`/`TvRemoteContext` (#277) attach one root platform listener lazily on `0 -> 1` subscribers and detach on `1 -> 0` (web DOM, Android raw + `BackHandler`, or `TVEventHandler` + refcounted `TVEventControl` + `BackHandler`) with throwing-subscriber isolation, `TextEntryBoundary` support above/below the provider, and `boolean` event consumption propagation (`#425`) so unconsumed root Android TV `Back` exits cleanly. `useTvKeySource` subscribes to the shared dispatcher inside `TvRemoteProvider` and falls back directly outside it.
- **Input guards & focus regions (`web-keys.ts`, `touch-hover-guard.ts`, `TvFocusAnchor.tsx`, `TvFocusGuideRegion.tsx`):** `subscribeWebKeys` drops IME composition (`isComposing`, `Process`, `keyCode === 229`), auto-repeats, and modifiers while preserving native editing (`Escape` blurs); `isEditableWebTarget` detects `INPUT`/`TEXTAREA`/`SELECT`, `contentEditable`, and ARIA `textbox`/`searchbox`/`combobox` (#136, #139). `createTouchHoverGuard(windowMs = 600)` suppresses synthetic post-touch hover (#139). `TvFocusAnchor` renders a 1×1 transparent focusable `View` so empty/loading tvOS screens retain focus (#186); `TvFocusGuideRegion` wraps native `TVFocusGuideView` keeping native `enabled={true}` (so `react-native-tvos` never applies `display: 'none'`) while gating `autoFocus`/`focusable`/`trapFocus*` via `enabled` (#130, #281), with `View` fallback on non-TV/web.
- **Key interpreter & text entry (`android-keys.ts`, `use-key-interpreter.ts`, `text-entry.tsx`):** `createAndroidKeyAdapter` maps D-pad, media/TV keys (`stop`, `next`, `previous`, `captions`, `audioTrack`, `guide`, `info`, `search`, `lastChannel`), programmable color keys (`183–186` -> `colorRed`/`colorGreen`/`colorYellow`/`colorBlue`, #133), and gamepad shortcuts (`BUTTON_Y`/`L1`/`R1`, #439) while preserving raw tap/hold timestamps across JS stalls; `useKeyInterpreter` coalesces repeats with rAF ack and propagates `boolean | void` consumption (`false` = unconsumed, #425); `TvTextInput`/`TextEntryBoundary`/`useTextEntrySuspension` (#48) suspend non-`back` keys during editing and exit on short `back`.
- **Lists (`TvList.tsx`, `list-source.ts`, `src/list/ElvList.tsx`):** `TvList` windows `visibleRows + 4` memoized slots anchored every `512 * pool` rows; only single-row non-held steps with `!reduceMotion` run `Animated.timing` — jumps, holds, source swaps, and `reduceMotion` call `stopAnimation()` before `setValue` (#152). `ElvList` delegates to `TvList` on `'tv'` and `VirtualizedList` elsewhere.
