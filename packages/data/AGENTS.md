# data (`@elv/data`)

Schema, migrations, importers and `CatalogService` for catalog, EPG and user data, over `@elv/domain` ports.

## Commands
- `pnpm --filter @elv/data typecheck` / `test`; `pnpm -w check` runs every repository check.

## Rules
- Pure TypeScript: no `react`, `react-native`, `expo*`, `electron` or `node:*` imports. Allowed workspace deps: `@elv/domain`, `@elv/sources`.
- Source-first (`src/index.ts`), `>= 90%` line coverage. Only `test-db.ts` and `*-test-helpers.ts` besides tests touch `better-sqlite3` or `node:*`; `@elv/data/testing` re-exports `test-db.ts`. Disk/simulator gates live in `tools/test/import-*.test.ts`.
- Inside `transaction(fn)` use only `tx`; parameterize every statement; add any new `source_id` table to `TABLES_BY_SOURCE`.

## Public surface
- `createSyncSqlDriver(db)` (`driver.ts`): serialized promise queue + `close()`, `tx` bypasses queue and rejects nesting, `ROLLBACK` guarded against SQLite auto-rollback (`SQLITE_FULL` / `SQLITE_IOERR`).
- `openCatalog(db)` (`migrate.ts`, `schema.ts`, `schema-expected.ts`): pragmas (`WAL`, `busy_timeout=5000`, `synchronous=NORMAL`, `foreign_keys=ON`, `temp_store=MEMORY`, `journal_size_limit` 64 MiB), `MIGRATIONS` to `SCHEMA_VERSION` (v3 adds external-content FTS5 virtual tables `live_fts`, `movies_fts`, `series_fts` over `name_fold` with `unicode61` tokenizer, insert/delete/`AFTER UPDATE OF name_fold WHEN old.name_fold IS NOT new.name_fold` triggers, and initial `'rebuild'`; v2 adds `watch_progress` + `favorites`; v1 core tables and indexes), `PRAGMA table_info` column verification against `EXPECTED_TABLE_COLUMNS` (self-heals missing columns in one transaction) plus `sqlite_master` verification of `EXPECTED_FTS_TABLES` (missing required/FTS table returns `storage/schema-corrupt`), leftover `running` runs marked `failed/interrupted`.
- `CatalogService`, `queries.ts`, `search.ts`, `user-state.ts`, `manifest.ts` (`catalog.ts`): `createCatalogService(deps)` (`DEVICE_MAX_BODY_BYTES` 4 MiB, `DEVICE_BATCH_SIZE` 5,000), serialized `importSource` queue, `removeSource(id)` aborts queued/in-flight imports of `id` and awaits settlement before deleting rows (including `watch_progress`, `favorites`, and trigger-synced FTS5 entries) + secrets, `close()` aborts active imports and closes `db`, `queryItems` subquery-limits `placements` before joining item tables, `queryItemDetail` / `itemDetail(itemKey)` looks up live/movies/series via `UNIQUE (source_id, key)` with `plot` and resolves M3U logos at read time, `buildFtsQuery` + `querySearch` / `search(query, opts?)` run Turkish-folded prefix-AND BM25 FTS5 searches (`DEFAULT_SEARCH_LIMIT=40`, `MAX_SEARCH_LIMIT=60`, `MAX_SEARCH_TOKENS=12`) with read-time M3U logo resolution, `resolveStream` resolves Xtream URLs or M3U templates + `headers_json` (`userAgent`, `referer`, `other`) on live/movies/episodes using a cached per-source `StreamResolver`. `user-state.ts` provides `profile_id`-scoped Watch Progress (`saveWatchProgress`, `setItemWatched`, `getWatchProgress`, `listContinueWatching`, `listProgressByKeys`, `clearWatchProgress`, `isCompletedProgress`, `computeResumePositionMs`) and My List Favorites (`toggleFavorite`, `listFavorites`, `listFavoriteKeys`). `reconcileManifest` restores purged cache rows on Apple platforms.
- `foldText(text)` (`fold.ts`): Turkish-aware, accent- and punctuation-insensitive folding for `name_fold`.
- `templates.ts`: `detectSegmentRules`, `toTemplate`, `resolveTemplate`, `keyTemplate`, `hostOf` (strips default `:80`/`:443`). Templates `userinfo`, credential query params, independent Xtream `/<u>/<p>/<id>` segments, high-share (`>= 99%`) token positions, mixed-account low-cardinality positions, single-URL host tokens, and bare `/<u>/<p>/<num>` pairs; literal `{{` is `{{(}}`.
- `sources.ts` & `source-link.ts`: `addXtreamSource`, `addM3uSource`, `addSourceFromLink`, `getSource`, `updateSourceSettings`, `removeSource`, `removeSecrets`, `purgeSourceRows`, `SOURCE_ID`, `TABLES_BY_SOURCE`. Credentials and guide URLs live only in `SecretStore` (`source.<id>.xtream|playlist|urlvars`).
- `stream-resolver.ts`: `createStreamResolver(sourceId, deps)` + `createPlaytimeResolverCache` (caches per-source M3U `urlvars` and Xtream secrets, evicting on source mutations; guards corrupt `headers_json` and prefers `m3u8` when `outputFormats` only advertises `m3u8`).
- Runs (`import-run.ts`, `runs.ts`, `import-types.ts`): one `running` run per source/kind; `beforeCommit` stages secrets prior to SQLite cleanup commit (`onAbortOrFail` rolls back); empty source fails with `empty-source`, empty kind warns `catalog/kind-empty-<kind>`; runs `PRAGMA wal_checkpoint(TRUNCATE)` after commit.
- Xtream (`import-xtream.ts`, `writers.ts`): per-category fallback + uncapped retry on `too-large`; persists `outputFormats` in `SourceSettings`; `loadSeriesEpisodes` re-verifies series existence and `run_id` inside the write transaction (`unknown-series` / `source-not-found`) and chunks episode batches with `scheduler.yieldNow()`.
- M3U (`import-m3u.ts`, `m3u-gate.ts`, `m3u-headers.ts`, `m3u-rules.ts`, `m3u-templating.ts`, `writers-m3u.ts`): O(1) `VarBook` capped at `MAX_URLVARS_BYTES` (64 KiB, `source-format/urlvars-too-large`); `RuleBook` judges stream/logo/referer/header hosts separately; `headers_json` persisted on live, movies and episodes; `timeshiftDays` fallback on `live.catchup_days`; counts computed via SQL in `beforeCleanup`.
- Guide (`import-guide.ts`, `guide-match.ts`, `guide-commit.ts`, `guide-queries.ts`): streams XMLTV into `programmes_next` and swaps mapped channels in cleanup, yielding between batch chunks. `queryNowNext` (`MAX_NOW_NEXT_KEYS=60`), `queryEpgWindow` (`MAX_EPG_WINDOW_KEYS=40`, `MAX_EPG_WINDOW_SPAN_MS=48h`), and `queryChannelByNumber` (`idx_live_num`) run indexed lookups with zero full-table scans; `CatalogService` exposes `importGuide` (serialized via `import-queue.ts` alongside `importSource`), `nowNext`, `epgWindow`, and `channelByNumber` (with read-time M3U logo resolution).
